> **Operations & Data Analytics Professional**

## 🌟 Overview

A modern, high-performance, dark-minimalist portfolio website crafted with **Astro**, **Tailwind CSS**, and **TypeScript**. Built specifically to showcase enterprise spreadsheet modeling, Google Apps Script automation pipelines, and executive KPI dashboards to recruiters, hiring managers, and global collaborators.

### Key Sections:
- **Hero & Live Ops Badge:** Instant professional summary with real-time status badge and simulated ops pipeline snippet.
- **Key Metrics Bento Banner:** Quantified operational impact (120+ hours saved/mo, 99.9% accuracy, 50+ automated sheets).
- **About & Philosophy:** Operational mindset, core principles (Business-first analytics, zero-error rigor, SLA discipline).
- **Core Competency Pillars:** Advanced Excel, Google Sheets, Apps Script, KPI Dashboards, Process Optimization, and Team Leadership.
- **Interactive ROI / Hours Saved Simulator:** Dynamic calculator demonstrating the quantifiable financial and time value of workflow automation.
- **Featured Case Studies:** 5 deep dives into real-world business challenges, engineered solutions, and measurable outcomes.
- **Career Timeline:** Work history with quantified achievements and skill tags.
- **Skills Matrix:** Categorized technical and operational toolset with mastery badges.
- **Awards & Recognitions:** Enterprise honors for operational excellence and process innovation.
- **Expanding Stack:** Active learning path in SQL, Python, Power BI, and Modern Web Development.
- **Direct Contact Suite:** One-click copy email button, LinkedIn, GitHub, downloadable CV, and quick message form.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.0.0 or later)
- npm / pnpm / yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/mehedihassan-ops/portfolio.git

# Navigate into the project folder
cd mehedi-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

The site will be live at `http://localhost:4321`.

### Production Build
```bash
npm run build
```
Compiled static assets will be generated in the `dist/` directory, ready for immediate deployment.

## ✏️ Updating Content

All personal data, projects, metrics, and career information are cleanly separated in a single TypeScript configuration file:

👉 `src/data/portfolioData.ts`

To update your projects, skills, or resume link, simply modify this file—no HTML/CSS changes needed!

## 🌐 Deployment to Vercel

### Option 1: Via Vercel Web Dashboard (Recommended)
1. Push this repository to your GitHub account (`git push origin main`).
2. Visit [vercel.com](https://vercel.com/) and click **Add New Project**.
3. Select your repository.
4. Framework Preset will be automatically detected as **Astro**.
5. Click **Deploy**.

### Option 2: Via Vercel CLI
```bash
npm i -g vercel
vercel
```
